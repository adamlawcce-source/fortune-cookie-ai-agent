A tiny Node 22 program for the make.fun bounty
[Fortune Cookie for an AI Agent](https://make.fun/bounty/u-suroso-69-fortune-cookie-for-an-ai-agent-d1506e11).

`main.ts` writes one funny fortune cookie line to `/output/entry.txt`: a
fortune slip for an AI agent, whose lucky numbers are binary and its
remaining token budget. No network, no randomness, no input — the same line
on every run.

Run it with Node 22:

```sh
node main.ts
```
